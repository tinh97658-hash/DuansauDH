# Tài liệu lưu trữ

`legacy-site/` giữ nguyên nguồn website giới thiệu dự án cũ (Jekyll), gồm tài
liệu gốc, cấu hình theme, Gemfile/lockfile và hình mẫu. Nội dung công nghệ,
nhóm phát triển và quy trình trong đó có thể không còn khớp hệ thống hiện tại.

Nguồn này không tham gia build frontend/backend hoặc quy trình production.
Xem [tài liệu hiện hành](../README.md) và [hướng dẫn triển khai](../deployment.md).
